# معرفی پروژه

این پروژه یک **Telegram Intelligence Agent** مبتنی بر n8n است. کاربر نام یک کانال عمومی را به بات می‌دهد؛ سیستم پست‌های جدید را از نسخه عمومی وب تلگرام جمع‌آوری می‌کند، در Data Table ذخیره می‌کند، با LLM خلاصه و دسته‌بندی می‌کند و سپس هشدار، Digest یا پاسخ مستند ارائه می‌دهد.

## قابلیت‌ها

- افزودن، توقف و نمایش کانال‌های عمومی
- دریافت متن، لینک، زمان انتشار و تعداد بازدید پست‌ها
- جلوگیری از ثبت پست تکراری
- خلاصه‌سازی و تشخیص موضوع فارسی با LLM
- رتبه‌بندی محتوا بر اساس تازگی، بازدید و اهمیت محتوا
- هشدار کلمه‌ای بدون ارسال تکراری
- Digest روزانه و پاسخ به سؤال همراه با لینک پست منبع

## اجزای اصلی

| Workflow | کاربرد |
| --- | --- |
| Bot Control | دریافت دستورهای تلگرام، مدیریت Watchlist، Q&A و Alert |
| Channel Collector | جمع‌آوری زمان‌بندی‌شده پست‌های جدید کانال‌های عمومی |
| AI Enrichment & Alerts | خلاصه‌سازی، دسته‌بندی، امتیازدهی و هشدار |
| Daily Digest | ارسال خلاصه مهم‌ترین پست‌های ۲۴ ساعت اخیر |

## فناوری‌ها

`n8n`، `Telegram Bot API`، `Telegram Web Preview`، `OpenRouter`، `n8n Data Tables`، `JavaScript` و `Node.js`.

## حریم خصوصی

این Repository داده زنده، Token، API Key، chat ID یا خروجی اجرای n8n ندارد. برای راه‌اندازی چندکاربره، حتماً کنترل‌های ایزوله‌سازی داده و پاک‌سازی History را مطابق [راهنمای حریم خصوصی](PRIVACY.md) فعال کنید.
