# Demo guide | راهنمای دمو

## English

Record a 2–3 minute demo:

1. Show the four n8n workflows.
2. Add a public demo channel with `/add @channel`.
3. Run the collector and show a newly stored post.
4. Show `/latest`, one grounded `/ask` response with a source URL, an alert, and `/digest`.
5. Blur usernames, chat IDs, execution IDs, credential panels, and unrelated message content.

## فارسی

برای دموی رزومه‌ای یک ویدیوی ۲ تا ۳ دقیقه‌ای بسازید: نمای چهار Workflow، افزودن یک کانال عمومی آزمایشی، اجرای Collector، نمایش `/latest`، یک پاسخ `/ask` همراه لینک منبع، Alert و `/digest`. نام کاربری، chat ID، شناسه اجرا، Credentialها و پیام‌های نامرتبط را Blur کنید.
